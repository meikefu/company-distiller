# 战略认知分析提示词

针对反复出现的战略经营逻辑，生成不可变的 `inference` Claim 候选。不得直接把散文模型写入派生 Skill。

至少满足以下两项时，才能提升候选结论：

1. 在相互独立的数据源或行动中重复出现；
2. 能解释过去的产品、市场、招聘、定价、并购或资源配置选择；
3. 能预测一个具体且可观察的下一步行动；
4. 能将该公司与相近竞争者区分开。

每个候选项都要提供：

- 原子的主题、谓词和带类型的值；
- 支撑证据 ID 和派生所依赖的 Claim ID；
- 被解释的行动和可检验预测；
- 边界条件和反证；
- 有效/观察时间、策略、`decision` 与置信度维度。

一次性口号保留为有归属的 `statement` Claim；薄弱解释保留为 `proposed` 的 `hypothesis` Claim。不得把分析师观点、CRM 备注或单次访谈提升为公司战略，除非存在重复的公司级证据。
