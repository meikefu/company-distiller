# 数据源路由提示词

在抽取前对不可变的数据源版本进行分类。返回 `sources`、`records`、`events` 和 `evidence` 的候选项；不要直接生成最终 Markdown。

## 路由输出

| 数据源 ID | 数据源类型 | 外部 ID/版本 | 业务日期 | 观察时间 | 记录类型 | 目标领域 | 策略 ID | 备注 |
|---|---|---|---|---|---|---|---|---|

## 规则

- 只有内容版本完全相同时才复用数据源 ID；记录 SHA-256 内容哈希和可寻址定位符。
- 将内容归入公司本体、商业关系或产品使用与服务领域。
- 把结构化数据行保留为有类型的记录，不得用散文摘要替代 CRM、合同、工单或使用字段。
- 为阶段变化、访谈、合同状态变化、工单状态变化、使用观测和审核决定创建事件。
- 从数据源继承密级和允许受众。不得降低派生记录、事件、证据单元、Claim 或关系的策略级别。
- 使用稳定实体 ID 区分目标公司、法律实体、业务单元、人员/角色、账户、商机、合同、产品、订阅、工单和指标。
- 使用 `schemas/` 和 `references/system-architecture.md` 定义的数据源与记录词汇。
